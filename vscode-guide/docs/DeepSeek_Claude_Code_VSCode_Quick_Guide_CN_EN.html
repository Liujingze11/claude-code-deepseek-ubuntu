DeepSeek API 接入 Claude Code VS Code 插件

Using DeepSeek API in Claude Code for VS Code
一句话：不要点登录页的三个按钮；开启 Disable Login Prompt，然后配置 ~/.claude/settings.json。
Bottom line: do not click the three login buttons; enable Disable Login Prompt, then configure ~/.claude/settings.json.

1. VS Code 插件设置 / Extension setting

  • 打开 VS Code 设置：Ctrl + ,（Mac 是 Cmd + ,）。
    Open VS Code Settings: Ctrl + , on Windows/Linux, Cmd + , on Mac.
  • 搜索 Claude Code login，勾选 Disable Login Prompt。
    Search Claude Code login, then enable Disable Login Prompt.
"claudeCode.disableLoginPrompt": true

2. 创建配置文件 / Create shared settings

Linux / Mac: ~/.claude/settings.json
Windows: C:\Users\<username>\.claude\settings.json

mkdir -p ~/.claude
nano ~/.claude/settings.json

3. 粘贴配置模板 / Paste this configuration

把 <your DeepSeek API Key> 替换成你的真实 DeepSeek API Key。
Replace it with your real DeepSeek API key.
{
  "$schema": "https://json.schemastore.org/claude-code-settings.json",
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.deepseek.com/anthropic",
    "ANTHROPIC_AUTH_TOKEN": "<your DeepSeek API Key>",
    "ANTHROPIC_MODEL": "deepseek-v4-pro[1m]",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "deepseek-v4-pro[1m]",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "deepseek-v4-pro[1m]",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "deepseek-v4-flash[1m]",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "CLAUDE_CODE_EFFORT_LEVEL": "max"
  }
}
不要把这个文件提交到 Git；里面有你的 API Key。
Do not commit this file to Git if it contains your API key.

4. 重载并开始使用 / Reload and start

  • Ctrl + Shift + P → Developer: Reload Window
  • 左侧 Claude Code 图标 → New session
    Click the Claude Code icon in the sidebar, then click New session.

终端保底方案 / Terminal fallback

npm install -g @anthropic-ai/claude-code
claude --version

cd /path/to/my-project
claude

快速排错 / Quick troubleshooting

问题 / Problem检查 / Check处理 / Fix
仍是登录页disableLoginPrompt 是否为 true重载窗口，确认 VS Code settings.json
Key 报错ANTHROPIC_AUTH_TOKEN重新复制 DeepSeek API Key
New session 无响应先跑 claude 终端版确认 CLI 能正常请求
